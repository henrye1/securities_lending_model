# Securities Lending Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CYTE Risk Suite web app that reproduces the "Stock Lending Model" workbook flow (Input → Portfolio → Calculate → Report) with value-for-value parity on the workbook's Excelcior Shipping example.

**Architecture:** FastAPI backend with a pure-Python Monte-Carlo engine (`backend/app/domain`), reference data exported from the workbook into JSON, a JSON dev store (Supabase optional), and a React/Vite/Tailwind frontend using the sibling apps' CYTE shell. Runs are immutable snapshots of inputs + results; the report tab prints and exports to a CYTE-branded xlsx.

**Tech Stack:** Python 3.12, FastAPI, pydantic v2, openpyxl, pytest · React 19, Vite, TypeScript, Tailwind 3, react-router 7, clsx.

**Spec:** `docs/specs/2026-10-20-securities-lending-model-design.md` (read it first; every formula below is defined there by Calculations cell reference).

## Global Constraints

- Python `>=3.11,<3.14`; dev venv is `py -3.12`. No numpy/pandas/scipy in `backend/app`.
- Ports: backend `8003`, frontend `5176` (siblings own 8000–8002 / 5173–5175).
- Branding copy: header `CYTE` + `Risk Suite`; nav label `Securities Lending Calculator`; footer `CYTE Risk Suite — Securities Lending (Share Cover) Model · PD, LGD, EL & RWA for share-backed lending`; `<title>` `CYTE Risk Suite — Securities Lending Model`.
- Tailwind palette identical to `../global-finance-model/frontend/tailwind.config.ts` (`cyte.navy #001080`, `navyHover #102090`, `navyDark #000860`, `panel #DBE3F1`, `lavender #C7CAE5`, RAG green/amber/red + Bg variants).
- UI labels = the workbook's Input / Portfolio / Print Report labels verbatim.
- Reference JSON under `backend/app/data/reference/` is generated by `scripts/export_reference.py`; never hand-edited.
- Default random draws = the workbook's `Random Numbers!A1:J10000`; quirks Q1/Q2 apply only then.
- Golden tolerance: `rel=1e-9` for engine values, `abs=1e-12` where the expected value is 0.
- Commit after every task (`Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` trailer).

## Review Focus

1. Maturity shorter than 10 years (e.g. 2.5 y): `dt` becomes 0 after maturity; averages must skip those years and `Conditional_Average` must use `floor(P)` iterations — pinned in Task 7 (`test_short_maturity_years`).
2. Amortised structures with "Not Applicable" bullet amount: `E12=E13=0`, cover ratio divides by amortised amount only — pinned in Task 7 (`test_structure_rules`).
3. Interest-rate buckets: `rate_lookup` with cover ratio below the first bound must still return the first rate (Excel LOOKUP would error; the engine returns 1000 cover on error paths only for AF) — pinned in Task 3 (`test_excel_lookup_below_first_bound`).
4. Risk grade lookup at the top of the scale (PD ≥ 0.99999…) must return `D1`, and PD of exactly a lower bound returns that grade — pinned in Task 4.
5. Portfolio mode with fewer than 10 stocks: empty stock columns contribute 0 value and must not produce NaN in the correlation volatility — pinned in Task 6 (`test_portfolio_four_stocks_matches_workbook`).
